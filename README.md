# Gamma-attenuation-calculator
For gamma ray in a variety of shielding materials under the attenuation coefficient calculation of the program.  
Date:26.4.30
Migrated the original C# WinForms gamma attenuation calculator to a Qt Widgets C++ application. The upgraded version keeps the original single-element attenuation calculation and input validation behavior, adds Chinese/English UI support, and introduces mixture attenuation calculation by either molecular formula parsing or manually entered element mass percentages.
